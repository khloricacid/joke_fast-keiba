# ファスト競馬

5秒で決着する3D競馬のジョークゲームです。馬をタップした瞬間に発走します。

- 賭けるのはゲーム内コインだけです。お金は賭けられず、コインの購入も換金もできません。
- 単勝のみ。1着を当てると賭け金×オッズが戻ります。連勝すると払い戻しにボーナスが付きます。
- BGMと効果音はすべてブラウザ内で合成しています(音声ファイルなし)。
- 8レースに1回ほど「ゴールデンレース」(払戻2倍)が来ます。賭けられるようになってから2秒以内に賭けると「秒で決断」ボーナス(×1.1)が付きます。
- 光の点滅や画面の揺れが多いゲームです。「メニュー」→「演出」で控えめにできます(OSの「視差効果を減らす」設定にも従います)。
- 初めて開いた人には、ジョークサイトであることを知らせるダイアログを1回だけ出します。

## 遊びの要素

- **実績 92種類**(銅・銀・金・隠し)。「実績」ボタンから一覧と進み具合を見られます。
- **デイリーミッション**:毎日3つ。達成すると宝箱(中身は開けるまでわからない)。
- **ログインボーナス**:連続日数で増え、7日目はおまけつき。
- **コンボ**:続けて賭けるとゲージがたまり、満タンで次のレースの払戻×1.3。
- **ジャックポット**:ハズレの2割が積み立てられ、払戻30倍以上の的中で全額もらえます(ブラウザごと)。
- **救済くじ**:ハズレのあと、ときどき引けます。
- **確定演出**:当たるレースでだけ、最後の直線で時間が止まり、画面いっぱいに「激アツ!!」が出ることがあります。
- **伝説**:騎手の特殊能力が虹(伝説)で発動すると、プチュン!と画面が十字に消えて暗転し、その馬が必ず勝ちます。大穴ほど発動が遅くなります。全ツッパで賭けると、そのセッションで賭けた合計に応じて自分の馬が伝説になる確率が上がります(4%〜15%上乗せ、伝説が出たらリセット)。
- **ドパミンRUSH**:自分の馬の伝説で勝つと突入。賭けるたびに40%で伝説になり、勝ち続けるかぎり続きます。1回でも外したら終わり。
- **馬主の援助**:破産したとき10%の確率で、賭けていた馬の馬主が現れ「こんなところでへこたれてはだめだ」とコインをくれます。
- **騎手のセリフと特殊能力**:賭けたとき・発走・先頭・勝ち負けで騎手がひとこと言い、特殊能力が発動するとカットインが出ます。
- レベルで見た目が解放されます(光の尾、名札、文字、花火など)。
- メニューから実況の読み上げ(ブラウザの音声合成)をオンにできます。

## レースの強さ

いちばん大きいのはその日の調子(運)です。そこに馬の能力・騎手の能力・得意脚質の相性・馬の特性・騎手の特殊能力が少しずつ上乗せされます。
オッズはこれらから計算します(特殊能力は「発動するかもしれない分」を織り込み済み)。払い戻し率は約94%です。

- 騎手の特殊能力が発動するとカットインが出ます。色は期待度で、青→緑→赤→金→虹の順に効果が大きくなります(虹は2%)。
- 馬の特性には、空の種類(ナイター・夕焼け・オーロラ)で効くものと、確率で出るものがあります。
- 馬柱の↑↓は調子、★は特殊能力が出やすい組み合わせ、緑の下線は騎手の得意脚質が合っている印です。
- 次に出るレースはブラウザに保存されるので、リロードしても引き直せません。レース中に閉じた賭けは、次に開いたときに精算します。

## 馬と騎手

[データページ](db.html)に、各馬の能力・特性・血統・近走、騎手のプロフィール・特殊能力・セリフ集、ニュース記事があります。
馬・騎手・レース・記事はすべて架空です。

## マルチプレイ

ページを開くと「みんなの部屋」に入ります。同じURLを開いた人は、全員が同じレースに賭けます。
身内だけで遊ぶときは「友だちを呼ぶ」→「専用の部屋を作る」で部屋コード付きのURL(`?room=xxxxxx`)を作り、それを送ってください。

通信は WebRTC のP2Pです。相手を見つける最初の合図だけ、公開されている Nostr リレーと MQTT ブローカーを使います([Trystero](https://github.com/dmotz/trystero))。
サーバーは持たないので、回線の種類(厳しいNATや社内ネットワークなど)によってはつながらないことがあります。
各自の所持コインや順位は自己申告で、不正対策はしていません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | ゲーム画面 |
| `game.js` | ゲーム本体(レース生成、進行、3D、音、演出、実績、ミッション) |
| `data.js` | 馬30頭(特性つき)・騎手10人(セリフ・特殊能力つき)・ニュースの設定。ゲームとデータページの両方が読む |
| `achievements.js` | 実績・デイリーミッション・レベル解放の定義 |
| `about.js` | 初回のジョークサイト告知ダイアログ(両ページ共通) |
| `db.html` / `db.css` / `db.js` | 馬・騎手・ニュースのデータページ |
| `vendor/three.min.js` | three.js r128(MIT) |
| `vendor/net.js` | Trystero 0.27 をまとめた通信層(MIT)。元のコードは `src/net-src.js` |

ビルドは不要で、静的ファイルとしてそのまま配信できます。`vendor/net.js` を作り直すときだけ次を実行します。

```sh
npm i trystero @trystero-p2p/nostr @trystero-p2p/mqtt esbuild
npx esbuild src/net-src.js --bundle --format=iife --global-name=FKNet --minify --target=es2020 --outfile=vendor/net.js
```

## 開発メモ

- `?demo=puchun` を付けると、伝説と馬主の援助を実際のレースの中で出せる確認用モードになります(ひとりで再生し、記録は保存しません)。
- `?debug=1` を付けると `window.__fk` から内部状態を触れます(コインは元々自己申告なので、不正対策上の差はありません)。
- `?relay=ws://localhost:1884` で、手元の MQTT ブローカーだけを使って接続を試せます。
- レース生成の計算を変えたら、`game.js` の通信の版(`fk`)を上げてください。版が違う人どうしは同じ部屋になりません。
