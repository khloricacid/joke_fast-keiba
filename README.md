# ファスト競馬

5秒で決着する3D競馬のジョークゲームです。馬をタップした瞬間に発走します。

- 賭けるのはゲーム内コインだけです。お金は賭けられません。
- 単勝のみ。1着を当てると賭け金×オッズが戻ります。連勝すると払い戻しにボーナスが付きます。
- BGMと効果音はすべてブラウザ内で合成しています(音声ファイルなし)。
- 8レースに1回ほど「ゴールデンレース」(払戻2倍)が来ます。発走から2秒以内に賭けると「秒で決断」ボーナス(×1.1)が付きます。
- レベルと称号、実績があります。記録はブラウザに保存されます。
- 光の点滅や画面の揺れが多いゲームです。右上の「演出全開」を押すと控えめになります(OSの「視差効果を減らす」設定にも従います)。

## 遊びの要素

- **実績 82種類**(銅・銀・金・隠し)。「実績」ボタンから一覧と進み具合を見られます。
- **デイリーミッション**:毎日3つ。達成すると宝箱(中身は開けるまでわからない)。
- **ログインボーナス**:連続日数で増え、7日目はおまけつき。
- **コンボ**:続けて賭けるとゲージがたまり、満タンで次のレースの払戻×1.3。
- **ジャックポット**:ハズレの2割が積み立てられ、払戻30倍以上の的中で全額もらえます(各自のブラウザごと)。
- **救済くじ**:ハズレのあと、ときどき引けます。
- **確定演出**:当たるレースでだけ、ゴール前で空が虹色になることがあります。
- **騎手のセリフ**:賭けたとき、発走、先頭、勝ち負けで騎手がひとこと言います。
- レベルで見た目が解放されます(光の尾、名札、文字、花火など)。
- メニューから実況の読み上げ(ブラウザの音声合成)をオンにできます。

初めて開いた人には、ジョークサイトであることを知らせるダイアログを1回だけ出します。

## 開発メモ

- `?debug=1` を付けると `window.__fk` から内部状態を触れます(コインは元々自己申告なので、不正対策上の差はありません)。
- `?relay=ws://localhost:1884` で、手元の MQTT ブローカーだけを使って接続を試せます。
